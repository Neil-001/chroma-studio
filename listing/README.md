# Listing

The Modrinth and CurseForge project pages, and the images they share.

- `description.md` is the description. Both sites use this one file as it is.
- `media/` holds the images, which both pages load from `main`. A new or changed image shows on the pages once it's merged there.
- `gallery/` holds the screenshots for the two sites' galleries, which are uploaded by hand.
